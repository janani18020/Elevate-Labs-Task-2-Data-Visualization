# Elevate Labs Task 2 - Data Visualization and Storytelling

## Objective

The objective of this project is to analyze sales data and create visualizations that communicate important business insights clearly.

## Dataset

The dataset contains **1,200 sales records and 9 columns**, including:

- Order ID
- Date
- Region
- State
- Category
- Product
- Quantity
- Sales
- Profit

## Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab

## Visualizations Created

1. Total Sales by Category
2. Total Sales by Region
3. Monthly Sales Trend
4. Total Profit by Category

## Key Business Insights

- Technology generated the highest total sales among the categories.
- North America recorded the highest sales among the regions.
- Monthly sales showed fluctuations with peaks and drops.
- Technology also generated the highest total profit.
- Sales and profit analysis can help identify areas for business growth.

## Deliverables

- `Task2_Sales_Visual_Report.pdf` - Visual report containing charts and business insights.
- `Task2_Data_Visualization.ipynb` - Google Colab notebook containing the analysis and visualizations.
- `sales_data.csv` - Dataset used for the analysis.
